Create with your own assistant

Take Motion Lab with you.

Use a desktop with Node.js 22 or newer and an AI coding assistant. The download contains the player, examples and skill. It does not run anything until you start it.

  1. Download and unzip the toolkit.Download toolkit .zip ↓Or clone the repository:
    git clone https://github.com/carldiederichs/motion-lab.git
  2. Open the folder in a terminal.
    cd motion-lab
    npm run dev
    Open http://127.0.0.1:4173. No dependency install is needed to explore or build.
  3. Open your assistant in this folder and ask:
    Use the motion-lab skill to explain how a retry can create duplicate records. Show the broken and safe versions.
    The skill is included in .agents/skills/motion-lab/. Assistants without skill discovery can read that file directly.

Generated work stays in local/, outside the public build. A local file may still be sent to your model provider by your chosen assistant.
