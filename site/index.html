Run Motion Lab locally

The repository includes the player, examples and a skill for your AI coding assistant. You’ll need a desktop with Node.js 22.13 or newer. Motion Lab is free to use, modify and share under the MIT license.

  1. Clone the repository. View on GitHub ↗ 
    git clone https://github.com/carldiederichs/motion-lab.git
    Prefer a download? Download the toolkit ZIP and unzip it before continuing.
  2. Open the folder in a terminal. 
    cd motion-lab
npm ci --ignore-scripts
npm run dev
    Open http://127.0.0.1:4173. The gallery runs locally in your browser.
  3. Describe your own engineering question.

    Open this folder in your own file-capable AI coding assistant. In Codex, select Motion Lab from the / skill menu, or type $motion-lab. Replace the bracketed text below with your question or relevant code. 

    $motion-lab Explain [my code, system or engineering question] visually. Show what moves, what changes and why. Include a contrasting case.

    If your assistant does not discover the skill, use this instead:

    Read .agents/skills/motion-lab/SKILL.md and use it to create a visual explanation of [my engineering question]. Build it, verify it and show me the local result.
    The gallery shows starting points. You can ask about your own algorithms, architecture, requests or state changes. Your assistant creates and revises the explanation locally using your chosen model; this website does not connect to a model.

Generated work stays in local/, outside the public build. A local file may still be sent to your model provider by your chosen assistant.
